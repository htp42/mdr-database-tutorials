# mdr-database-tutorials

clinical-mdr.adoc is an old stab at creating a Neo4j Browser guide to walk through the data model. Queries might be outdated.

Theoretically (untested), using the toolchain in https://github.com/neo4j-contrib/neo4j-guides to generate an HTML would allow loading this as a guide for the new Neo4j Browser guide.

Alternatively, all queries in this guide are included in `saved_cypher.csv`, which can be imported into the new Neo4j Browser to have a list of pre-set Cypher queries.
